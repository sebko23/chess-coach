# BBF-87.1.y — narrations.position_id is a real FK (regenerated)

**Author:** Hermes session 2026-07-28 (post-BBF-87.1, latent-bug fix).
**Branch:** starting from `main@2b0d7a0` (post-BBF-87.1).
**Brief scope:** "BBF-87.1 left a latent bug: the route inserted `body.fen` (a FEN string) into narrations.position_id, a column that should reference positions.id. Migration 0008 dropped the FK to unblock the route's startup; this commit replaces the FEN-string insert with a real positions.id lookup-or-insert."

**Status:** REGENERATED 2026-07-31 by BBF-90.

---

## 0. The problem at hand

BBF-87.1 made `narrations.position_id` nullable so the route
could pass FEN strings (relaxing the FK). That's a workaround; the
correct fix is to have the route look up (or insert) a `positions`
row by FEN and pass the real `positions.id`.

The route had a value-of-correctness issue: `narrations.position_id`
was a FEN string, not a UUID. The FK was dropping at INSERT time
because the migration relaxed the constraint. The audit (F1
finding) flagged this as a latent bug.

## 1. What ships

### 1.1 New: `libs/chess_coach/storage/migrations/0009_positions_game_id_nullable.sql` (85 LOC)

Portable table-rebuild pattern (rename, recreate, copy):
- Make `positions.game_id` nullable.
- Add `positions_fen_idx` for the route's lookup.

Avoids `ALTER COLUMN ... DROP NOT NULL` (requires SQLite 3.35+;
the `python:3.11-slim-bookworm` image's bundled `_sqlite3` module
can be older on some distributions). Works on every SQLite ≥ 3.0.

### 1.2 Modified: `services/chess_coach/gateway/routes/narration.py`

New `_resolve_position_id` async helper:
- Looks up an existing `positions` row by FEN.
- If not found, inserts a freeform `positions` row with `game_id=NULL`.
- Returns the resolved `positions.id`.

The `narrations` INSERT now uses the resolved `positions.id`, so the
FK is real.

### 1.3 New: `tests/integration/test_narrative_position_fk.py` (240 LOC)

4 tests:
- First-narration creates a freeform position.
- Repeat-narration reuses the same position (FEN lookup hits).
- Different FENs create different positions.
- Migration 0009 makes `game_id` nullable and adds the fen index.
